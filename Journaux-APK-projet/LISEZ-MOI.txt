JOURNAUX - PROJET POUR COMPILER L APPLICATION ANDROID (APK)
==========================================================

Ce dossier est à placer A LA RACINE de votre dépôt GitHub
(package.json, capacitor.config.json, www/, android/, .github/ au même niveau).

1. Supprimez de votre dépôt l ancien contenu : le dossier "Journaux-Android"
   et l ancien fichier .github/workflows/build.yml.
2. Ajoutez les fichiers de ce zip à la racine (dossiers compris, dont .github).
3. Onglet "Actions" du dépôt > "Compiler Journaux (APK)" > Run workflow
   (ou simplement un nouveau commit sur la branche principale).
4. Quand la ligne est verte : ouvrez l exécution > "Artifacts" > "Journaux-APK".
   Le téléchargement est un zip contenant app-debug.apk.
5. Sur le téléphone : ouvrez l APK, autorisez l installation depuis cette source si Android le demande.

Données : l app démarre vide. Ancienne version : Paramètres > Sauvegarder mes données ;
nouvelle app : Paramètres > Restaurer une sauvegarde > coller.

Remarques : c est un APK de test (signé avec la clé de debug), parfait pour un usage personnel,
mais pas pour Google Play. Les rappels s affichent dans l app quand elle est ouverte.
Pour modifier l application, éditez www/index.html puis relancez la compilation.
