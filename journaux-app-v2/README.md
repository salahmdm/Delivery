# Journaux — app de livraison
1. supabase.com → New project → SQL Editor → coller et lancer `supabase.sql`.
2. Settings > API : copier "Project URL" et la clé "anon public" dans le haut de `www/index.html`.
3. Créer un repo GitHub, y pousser tout ce dossier. Onglet Actions → "Build APK" → télécharger l'artefact `journaux-apk` (app-debug.apk).
4. Installer l'APK sur Android (autoriser les sources inconnues). Connexion patron : Patron / 1234 (changez le PIN).
